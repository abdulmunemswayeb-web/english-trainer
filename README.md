# مدرّب الإنجليزية — للتحدث الفعلي

تطبيق ويب لتعلّم الإنجليزية موجَّه للاستعمال الحقيقي: **المعارض التجارية الدولية، التفاوض مع
الشركات والموردين، المطار والفنادق والمطاعم، والتعرّف على الناس**. لا قواعد نظرية ولا امتحانات
أكاديمية — القاعدة تصل داخل موقف، والشرح سطر واحد بعد الإجابة.

ملف HTML واحد، بلا خادم وبلا اعتماديات، جاهز للنشر على GitHub Pages.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادماً محلياً ليقرأ التطبيق بنك الأسئلة من `data/`:

```bash
python3 -m http.server 8000   # ثم http://localhost:8000
```

للنشر: Settings ← Pages ← Deploy from branch ← الفرع والجذر `/`.

## الهيكل

```
index.html            التطبيق كاملاً
sources/              ملفات PDF و Word تضعها أنت
data/questions.json   بنك الأسئلة — المرجع الوحيد
data/processed.json   سجل الملفات المعالَجة
CLAUDE.md             التعليمات الدائمة لتوسيع البنك
```

`data/questions.json` هو المرجع. يقرأه التطبيق عبر `fetch` عند التشغيل من خادم أو GitHub Pages،
وعند فتح الملف مباشرة من القرص (`file://`) يقع على نسخة احتياطية مدمجة داخل `index.html`
بين `SEED-BANK-START` و`SEED-BANK-END` — تُحدَّث مع كل تعديل للبنك.

## أنواع الأسئلة

| النوع | ماذا يطلب |
| --- | --- |
| `word` | معنى كلمة إنجليزية — مع النطق، والترجمة، وجملة مثال من مجالك |
| `fill` | إكمال فراغ داخل موقف حقيقي (جناح معرض، اجتماع مورّد، استقبال فندق) |
| `translate` | ترجمة جملة عربية إلى الإنجليزية تكتبها بنفسك |
| `order` | ترتيب كلمات مبعثرة لتكوين جملة |

بعد كل إجابة: الجملة الصحيحة كاملة + **سطر واحد** يوضح المعنى — مثل
`have been = بدأ في الماضي ومستمر`.

## نظام المراجعة — Leitner بخمسة صناديق

| الصندوق | متى يعود السؤال |
| --- | --- |
| ١ | في نفس الجلسة |
| ٢ | بعد يوم |
| ٣ | بعد ٣ أيام |
| ٤ | بعد أسبوع |
| ٥ | بعد ٣ أسابيع |

الإجابة الصحيحة ترفع السؤال صندوقاً واحداً، والخطأ يرجّعه إلى الصندوق الأول ويعيده في
نفس الجلسة. الجلسة عشرة أسئلة تُختار حسب الاستحقاق، وتضمن كلمة جديدة واحدة على الأقل يومياً.
التقدّم محفوظ في `localStorage`.

## التكيّف

كل سؤال موسوم بمهارة (`skill`). التطبيق يحسب نسبة الخطأ لكل مهارة، ويقدّم أسئلة المهارات
الضعيفة أولاً عند اختيار الأسئلة الجديدة. شاشة **تقدّمي** تعرض نقاط الضعف صراحةً.

## توسيع بنك الأسئلة

ضع أي ملف PDF أو Word في `sources/` واطلب من Claude معالجته. الخطوات مفصّلة في `CLAUDE.md`:
يقرأ الملف، يستخرج ما يناسب مستواك ومجالاتك، يتجنّب تكرار الموجود، يولّد أسئلة بالأنواع
الأربعة موسومة بـ `src` باسم الملف، يضيفها دون حذف شيء، ويسجّل الملف في `data/processed.json`.

الملفات ليست المصدر الوحيد — `CLAUDE.md` يوجّه أيضاً إلى سدّ الفجوات من خارج الملفات:
الكلمات الأكثر استعمالاً، تعابير التفاوض التجاري، والأخطاء المتكررة عند الناطقين بالعربية
(a/an · in/on/at · البسيط بدل المستمر · ترتيب الصفة · make/do · between/among).

## الحالة

٣٠ سؤالاً مبدئياً تغطي: المضارع التام، الطلب المهذب، حروف الجر، النفي، صياغة السؤال،
الماضي البسيط، الشرط الأول، المقارنة، المضارع المستمر، وأربعة من أشيع أخطاء العرب —
موزّعة على مواقف المعارض والموردين والفنادق والمطاعم والتعارف.

ملفات `sources/` الخمسة **لم تُعالَج بعد** (`data/processed.json` فارغ) — اطلب معالجتها لتوسيع البنك.
