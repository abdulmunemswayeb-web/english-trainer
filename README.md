# english-trainer — مدرّب الإنجليزية

تطبيق تعلّم الإنجليزية بنظام المراجعة المتباعدة (Spaced Repetition)، بواجهة عربية كاملة
من اليمين إلى اليسار. يعمل بالكامل داخل المتصفح — بدون خادم، وبدون تثبيت، وبدون اتصال بالإنترنت
بعد أول فتح — ويُحفظ التقدّم محلياً في المتصفح.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

يمكن نشره كما هو على GitHub Pages أو أي استضافة ملفات ثابتة.

## المحتوى

| المصدر | المحتوى |
| --- | --- |
| مرجع المفردات A1 → B2 | ١٨٤ مدخلاً في ٢٦ مجموعة (تحيات، أرقام، عائلة، ألوان، أفعال، وقت، طعام، أماكن، روتين يومي، سفر، تسوق، صفات، حروف جر، عمل، طقس، مشاعر وآراء، أفعال مركبة، وصف التجارب، أعمال ومال، أدوات ربط، صحة، مفردات رسمية، تفاوض واجتماعات، تعبيرات اصطلاحية، تحليل وتقارير، معارض وتواصل مهني) |
| دليل المحادثة: المطعم | ١٢ جملة |
| دليل المحادثة: المقهى | ١١ جملة |
| دليل المحادثة: الشقق والعقارات | ٢٠ جملة |
| دليل المحادثة: المطار | ٢٤ جملة |

المجموع: **٢٥١ بطاقة** قابلة للمراجعة. كل جملة محادثة تحتفظ بتفكيكها *كلمة بكلمة* كما في الأدلة الأصلية.

## الشاشات

- **الرئيسية** — هدف اليوم، سلسلة الأيام المتتالية، توزيع البطاقات (جديدة / قيد التعلم / معروفة / متقنة)، ومداخل سريعة لأدلة المحادثة.
- **المراجعة** — جلسة بطاقات: يظهر السؤال، تكشف الإجابة، ثم تقيّم نفسك بأربع درجات (نسيت / صعب / جيد / سهل) فيحدّد النظام موعد المراجعة القادمة. البطاقة المنسية تعود في نهاية الجلسة نفسها.
- **اختبار** — عشرة أسئلة اختيار من متعدد مع تسجيل أفضل نتيجة، وتؤثّر إجاباتك على جدولة البطاقات.
- **محادثة** — الأدلة الأربعة مع النطق والتفكيك كلمة بكلمة وحالة كل جملة.
- **المفردات** — تصفّح وبحث (بالعربية أو الإنجليزية) وتصفية حسب المستوى.
- **الإحصائيات** — نشاط آخر ١٤ يوماً، توقّع المراجعات لسبعة أيام قادمة، والتقدّم لكل مستوى.

## نظام المراجعة المتباعدة

الجدولة مبنية على خوارزمية **SM-2**:

- لكل بطاقة عامل سهولة (`ef`، يبدأ من 2.5 ولا ينزل تحت 1.3)، وفاصل زمني، وعدد تكرارات.
- الإجابات الصحيحة: يوم واحد → ستة أيام → `الفاصل السابق × عامل السهولة`.
- «نسيت» يعيد البطاقة بعد ١٠ دقائق ويصفّر عدّاد التكرارات.
- تُعتبر البطاقة **متقنة** عندما يتجاوز فاصلها ٢١ يوماً.

كل جلسة تبدأ بالبطاقات المستحقة، ثم تُكمل العدد ببطاقات جديدة ضمن الحد اليومي المضبوط في الإعدادات.

## الإعدادات

اتجاه السؤال (عربي ← إنجليزي، أو العكس، أو مختلط)، الهدف اليومي، عدد البطاقات الجديدة يومياً،
النطق التلقائي، والمستويات المُفعّلة. تدعم الشاشة أيضاً **تصدير واستيراد** ملف التقدّم بصيغة JSON،
ومسح كل البيانات.

## اختصارات لوحة المفاتيح (أثناء المراجعة)

| المفتاح | الوظيفة |
| --- | --- |
| `مسافة` أو `Enter` | كشف الإجابة |
| `1` `2` `3` `4` | نسيت / صعب / جيد / سهل |
| `S` | الاستماع للنطق |

## البنية

```
index.html                    الهيكل وشريط التنقل
assets/css/styles.css         التصميم (وضع ليلي ونهاري، RTL)
assets/js/data/vocabulary.js  مفردات A1–B2
assets/js/data/phrases.js     أدلة المحادثة الأربعة
assets/js/core.js             البطاقات، التخزين، خوارزمية SM-2، النطق
assets/js/app.js              الشاشات والتنقل
```

جافاسكربت خالصة بلا أي اعتماديات أو خطوة بناء. النطق عبر `SpeechSynthesis` في المتصفح،
والتخزين عبر `localStorage`.
